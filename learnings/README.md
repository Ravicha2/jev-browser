# learnings/

Per-site pruning rules and selector knowledge, one directory per site
(`learnings/<site>/`), in the spirit of ego-browser's own convention.

Read the site's directory when a round on that site escalates; write one when a
round surfaces a fix the next round on the same site should not have to
re-derive. Everything a rule needs to be trusted belongs in the file: the site
shape it applies to, the rule, and what was measured.
